# UI/UX Wireframes and Interactive Prototypes

A collection of wireframes, mobile interfaces, and web prototypes created as part of design planning for software engineering and web development projects.

## Included Designs
- Mobile app wireframes
- Website homepage prototypes
- User dashboard layouts
- User flow diagrams

## Tools Used
- Figma
- Canva
- Adobe XD

## Purpose
Created to strengthen user-centred design thinking, interface planning, and usability-focused software prototyping.
